# Velora Motors landing page

This repository contains a premium automotive landing page inspired by luxury performance brands. It is intentionally built as a lightweight static website so it can be opened quickly and published easily on GitHub Pages or any static hosting service.

## Features

- Responsive luxury landing page
- Dark premium visual system with editorial typography
- Vehicle showcase cards and innovation section
- Mobile navigation menu
- Accessible semantic markup and focus states
- Embedded JavaScript for small interactive enhancements

## Local preview

From the project root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu behavior and footer year

## Notes

This is a fan-made luxury automotive concept page and does not use official Mercedes-Benz trademarks or logos.
